# NirmanBazar · নির্মাণবাজার

**Bangladesh's Premier Construction Marketplace**
**বাংলাদেশের সর্বশ্রেষ্ঠ নির্মাণ সামগ্রীর বাজার**

A premium, fully responsive, bilingual (বাংলা / English) static web storefront showcasing **1,275+ construction products** across **145+ categories** — from cement and bricks to sanitary ware, tiles, doors, electrical, kitchen, paint and more.

## ✨ Features

- **Premium editorial design** — midnight navy + antique gold palette, glass-morphism header, serif/sans type system (Playfair Display · Inter · Hind Siliguri)
- **Bilingual UI** — seamless Bengali ⇄ English toggle across every label, heading, and card
- **1,275 products** sourced from aggregated supplier catalogs, each with title, image, price (৳), category, and description snippet
- **13 curated sections** (Construction Materials, Paint, Electrical, Kitchen, Sanitary, Doors & Windows, Tiles & Marble, Pipes, Rooftop, Tools, Safety, Real Estate, Services)
- **Smart filtering** — filter by section, browse by category chip, real-time search (300 ms debounce), and sort by price/name
- **Product detail modal** with full-size image, price, description, and contact CTAs
- **Featured collection** — algorithmic pick of high-value, image-rich items across every section for homepage variety
- **Trust bar, about section, contact form, footer** — complete marketing site structure
- **Fully responsive** — mobile-first, works beautifully from 360 px to 4K
- **Accessible** — semantic HTML, keyboard-navigable, respects `prefers-reduced-motion`
- **Zero build step** — pure HTML/CSS/JS, deploys to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages)

## 🗂 Structure

```
/
├── index.html                 # single-page app markup
├── products.json              # 1,275 products + 145 categories + 13 sections
└── assets/
    ├── css/style.css          # design system + layout + components
    └── js/app.js              # SPA: i18n, render, filter, search, modal
```

## 🚀 Local preview

```bash
# from repo root
python3 -m http.server 8000
# then open http://localhost:8000
```

Any static file server works — no build step needed.

## 🌐 Deploy

- **GitHub Pages**: Settings → Pages → deploy from `main` → `/` root
- **Netlify / Vercel / Cloudflare Pages**: connect repo → no build command → publish directory: `/`

## 📦 Data

`products.json` is generated by parsing the source HTML archives and extracting each listing's title, price, image, category, and description. The structure:

```json
{
  "brand": { "en": "NirmanBazar", "bn": "নির্মাণবাজার", "tagline_en": "…", "tagline_bn": "…" },
  "sections": [ { "id", "en", "bn", "icon", "category_count", "item_count" } ],
  "categories": [ { "slug", "name", "section", "count" } ],
  "listings":   [ { "title", "price", "image", "category_slug", "category_name", "section", "text", "description" } ]
}
```
